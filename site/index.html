Sheet 02 · How it worksClick any skill to open it

One context file. Every money question.

Run money-ops-context once. It writes down your household, income and pay schedule, expenses, debts, accounts, employer benefits, and goals. Every other skill reads that file first, so it only asks you for what's specific to the question. It never stores account numbers, Social Security numbers, or passwords.

Sheet 03 · RulesBuilt into every skill

What every skill holds to

The same four rules run through the whole library, so the plan you get is built on your numbers and this year's rules.

Rule 1

Your numbers, not averages.

Every answer is built from your own pay, bills, and debts. Rough is fine; made up is not.

Rule 2

This year's limits, looked up.

Contribution limits, credits, and loan rules change. Skills check them and cite the source.

Rule 3

Education, not advice.

No fund, stock, or provider picks. Skills lay out the choices. You decide.

Rule 4

No judgment.

Skills say where you are and the next step. Never that you're behind.
